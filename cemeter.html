주요 기능FUNCTIONS

  • 탄소당량, 탄소량, 규소량, 초정·공정 온도 측정
  • 10개 검량선 설정, 목표 성분 설정 기능 (검량선과 목표 재질의 설정은 자동계산 연동)
  • 자주 쓰는 재질 설정 (전면부 FC, FCD 버튼)
  • 최대 2분 30초 이내 측정결과 표시
  • USB/LAN 포트를 이용한 측정결과 인쇄 기능
  • 이력 조회에서 과거 측정결과 인쇄 기능
  • 측정결과 최대 3,000개 기록 (TE, TL, CE, C%, Si% 측정값, 초정·공정 온도 그래프)
  • USB 메모리 스틱으로 측정 데이터 이전
  • 측정결과를 UDP 통신으로, JSON 전문을 해당사 ERP에 연계
